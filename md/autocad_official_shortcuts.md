# AutoCAD 공식 단축키 안내서 (Autodesk 한국어판)

> 출처: Autodesk 공식 "AutoCAD 단축키 안내서" PDF (autocad-shortcut-guide-ko.pdf)

## 1. 단일 단축키 (기본 명령 별칭)

| 키 | 명령 | 설명 |
|:---|:---|:---|
| Q | QSAVE | 현재 도면을 저장합니다. |
| W | WBLOCK | 새 도면 파일에 객체 또는 블록을 씁니다. |
| E | ERASE | 도면에서 객체를 제거합니다. |
| R | REDRAW | 현재 뷰포트의 표시를 갱신합니다. |
| T | MTEXT | 여러 줄 문자 객체를 작성합니다. |
| I | INSERT | 현재 도면에 블록 또는 도면을 삽입합니다. |
| O | OFFSET | 동심원, 평행선 및 평행 곡선을 작성합니다. |
| P | PAN | 그립이 있는 매개변수를 동적 블록 정의에 추가합니다. |
| A | ARC | 호를 작성합니다. |
| S | STRETCH | 선택 윈도우 또는 폴리곤과 교차하는 객체를 신축합니다. |
| D | DIMSTYLE | 치수 스타일을 작성하고 수정합니다. |
| F | FILLET | 객체의 모서리를 둥글게 모깎기합니다. |
| G | GROUP | 그룹이라고 불리는 저장된 객체 세트를 작성하고 관리합니다. |
| H | HATCH | 닫힌 영역이나 선택한 객체를 해치 패턴, 솔리드 채우기 또는 그라데이션 채우기로 채웁니다. |
| J | JOIN | 끊기지 않는 단일 객체를 형성하도록 유사한 객체를 결합합니다. |
| L | LINE | 직선 세그먼트를 작성합니다. |
| Z | ZOOM | 현재 뷰포트에 있는 뷰의 배율을 늘리거나 줄입니다. |
| X | EXPLODE | 복합 객체를 구성요소 객체로 분해합니다. |
| C | CIRCLE | 원을 작성합니다. |
| V | VIEW | 명명된 뷰, 카메라 뷰, 배치 뷰 및 사전 설정 뷰를 저장하고 복원합니다. |
| B | BLOCK | 선택한 객체로 블록 정의를 작성합니다. |
| M | MOVE | 객체를 지정된 방향으로 지정된 거리만큼 이동합니다. |

## 2. 전환 및 화면 관리

### 도면 모드 전환 (F-키)

| 키 | 기능 |
|:---|:---|
| F1 | 도움말 표시 |
| F2 | 명령 윈도우 사용내역 전환 |
| F3 | 객체 스냅 모드 전환 |
| F4 | 3DOsnap 전환 |
| F5 | 등각투영 평면(Isoplane) 전환 |
| F6 | 동적 UCS 전환 |
| F7 | 그리드 모드 전환 |
| F8 | 직교 모드 전환 |
| F9 | 스냅 모드 전환 |
| F10 | 극좌표 모드 전환 |
| F11 | 객체 스냅 추적 전환 |
| F12 | 동적 입력 모드 전환 |

### 일반 기능 전환 (Ctrl)

| 키 | 기능 |
|:---|:---|
| Ctrl+D | 좌표 표시 전환 |
| Ctrl+G | 그리드 전환 |
| Ctrl+E | 등각투영 평면 순환 |
| Ctrl+F | 활성 객체 스냅 전환 |
| Ctrl+H | 스타일 선택 전환 |
| Ctrl+Shift+H | 팔레트 숨기기 전환 |
| Ctrl+I | 좌표 전환 |
| Ctrl+Shift+I | 구속조건 추정 전환 |

### 화면 관리 (팔레트)

| 키 | 기능 |
|:---|:---|
| Ctrl+0 (숫자) | 화면 정리 |
| Ctrl+1 | 특성 팔레트 |
| Ctrl+2 | Design Center 팔레트 |
| Ctrl+3 | 도구 팔레트 |
| Ctrl+4 | 시트 세트 팔레트 |
| Ctrl+6 | 데이터베이스 연결 관리자 |
| Ctrl+7 | 표식 세트 관리자 팔레트 |
| Ctrl+8 | 빠른 계산기 |
| Ctrl+9 | 명령행 |

### 워크플로우 관리

| 키 | 기능 |
|:---|:---|
| Ctrl+C | 객체 복사 |
| Ctrl+X | 객체 잘라내기 |
| Ctrl+V | 객체 붙여넣기 |
| Ctrl+Shift+C | 기준점을 사용하여 클립보드에 복사 |
| Ctrl+Shift+V | 데이터를 블록으로 붙여넣기 |
| Ctrl+Z | 마지막 작업 취소 |
| Ctrl+Y | 마지막 작업 복구 |
| Ctrl+[ (또는 Ctrl+\\) | 현재 명령어 취소 |
| ESC | 현재 명령어 취소 |

### 도면 관리

| 키 | 기능 |
|:---|:---|
| Ctrl+N | 새 도면 |
| Ctrl+S | 도면 저장 |
| Ctrl+O | 도면 열기 |
| Ctrl+P | 플롯 대화상자 |
| Ctrl+Tab | 다음 도면으로 전환 |
| Ctrl+Shift+Tab | 이전 도면으로 전환 |
| Ctrl+Page Up | 현재 도면에서 이전 탭으로 전환 |
| Ctrl+Page Down | 현재 도면에서 다음 탭으로 전환 |
| Ctrl+Q | 끝내기 |
| Ctrl+A | 모든 객체 선택 |
